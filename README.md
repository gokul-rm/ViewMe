# ViewMe

ViewMe is a full-stack GitHub repository analysis platform that allows users to analyze GitHub repositories and view repository statistics, contributors, issues, and repository history.

## Features

* Analyze GitHub repositories using repository URLs
* View repository description and topics
* View stars, forks, watchers, and open issues
* Display top contributors
* Display recent repository issues
* Search history with MySQL persistence
* Responsive React + Tailwind UI
* REST API backend using Express.js
